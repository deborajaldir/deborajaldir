## 🌷 Sobre mim

Desenvolvedora Full Stack com foco na construção de aplicações web utilizando **Java, Spring Boot, React, JavaScript e PostgreSQL**.

Desenvolvo projetos que envolvem criação de APIs REST, integração entre front-end e back-end, persistência de dados e organização do código em camadas. Também valorizo boas práticas de desenvolvimento, documentação e testes automatizados.

## Tecnologias

- **Back-end:** Java, Spring Boot, Spring Data JPA, Node.js, Express
- **Front-end:** React, JavaScript, HTML5, CSS3
- **Banco de dados:** PostgreSQL
- **APIs e documentação:** APIs REST, Swagger/OpenAPI
- **Testes:** Vitest, Jest
- **Ferramentas:** Git, GitHub, Docker

## Projetos

### Stock Control — Sistema de Controle de Estoque

Aplicação full stack para gerenciamento de produtos, com API desenvolvida em Java e Spring Boot e interface em React.

- Operações CRUD para gerenciamento de produtos
- Persistência de dados com PostgreSQL
- Arquitetura em camadas: Controller, Service e Repository
- Validações e tratamento de erros
- Integração entre front-end e back-end
